# Tender Parser

Python-проект для автоматизации обработки закупочных позиций и поиска соответствующих товаров у дистрибьюторов.

## О проекте

При работе с закупочными процедурами часть информации приходится обрабатывать вручную:

1. получить список закупочных позиций из Excel;
2. определить название товара;
3. найти соответствующий товар на сайте дистрибьютора;
4. получить цену и информацию о наличии;
5. сохранить результаты;
6. использовать полученные данные для дальнейшего участия в закупке.

**Tender Parser** создаётся для автоматизации этого процесса.

На текущем этапе проект представляет собой прототип Python-приложения, которое получает позиции из Excel, проверяет наличие данных в PostgreSQL и при необходимости выполняет поиск товара на сайте дистрибьютора.

## Текущий функционал

На текущем этапе реализован следующий pipeline:

```text
Excel
  │
  ▼
Чтение закупочных позиций
  │
  ▼
Нормализация названий
  │
  ▼
Проверка PostgreSQL
  │
  ├── Товар уже есть → пропуск поиска
  │
  └── Товара нет
          │
          ▼
    Поиск на сайте
          │
          ▼
    Browser automation
          │
          ▼
       HTML
          │
          ▼
    BeautifulSoup
          │
          ▼
  Структурированные данные
          │
          ▼
      PostgreSQL
```

### Получаемые данные

Для найденного товара система может сохранять:

- название;
- цену;
- валюту;
- наличие;
- артикул;
- part number;
- URL товара;
- характеристики;
- название магазина/дистрибьютора.

## Архитектура текущего прототипа

### `main.py`

Основная точка запуска приложения.

Отвечает за последовательность обработки:

- загрузка конфигурации;
- чтение Excel;
- проверка данных в БД;
- запуск поиска;
- сохранение результатов.

### `read_excel.py`

Отвечает за чтение исходного Excel-файла и преобразование строк таблицы в список товарных позиций.

### `database.py`

Содержит функции взаимодействия с PostgreSQL:

- создание соединения;
- поиск существующих позиций;
- сохранение результатов;
- обновление существующих записей.

### `models.py`

Содержит Python-модели результатов поиска.

### `parsers/`

Директория для реализации отдельных парсеров дистрибьюторов.

Предполагается, что каждый источник будет иметь собственную реализацию общей логики поиска.

## Особенности текущего парсера

Обычные HTTP-запросы не всегда подходят для современных сайтов: часть данных формируется JavaScript, а некоторые сайты используют механизмы защиты от автоматизированных запросов.

Поэтому текущий прототип использует браузерную автоматизацию через **Camoufox**.

Процесс получения данных:

```text
Поисковый запрос
      ↓
Запуск headless browser
      ↓
Открытие страницы
      ↓
Ожидание загрузки динамического контента
      ↓
Получение HTML
      ↓
BeautifulSoup
      ↓
Извлечение данных
```

После получения HTML парсер извлекает информацию из карточек товаров.

## Статус проекта

**Current status: Prototype / WIP**

Проект не является готовой системой, но уже используется в продакшене.

Сейчас реализован базовый сценарий работы с одним источником и PostgreSQL. Архитектура находится в процессе переработки по мере развития проекта.

Основная цель следующего этапа — превратить текущий прототип в минимально жизнеспособную версию (MVP), которую можно запускать воспроизводимо и использовать как демонстрационный backend-проект.

# MVP

Минимально жизнеспособная версия проекта должна позволять:

1. загрузить список закупочных позиций;
2. запустить обработку;
3. выполнить поиск по нескольким источникам;
4. получить структурированные результаты;
5. сохранить результаты в PostgreSQL;
6. повторно использовать уже найденные данные;
7. получить результаты через API;
8. запустить систему одной командой через Docker Compose;
9. развернуть систему на Linux VPS;
10. получить понятную документацию по запуску и использованию.

## Definition of Done для MVP

MVP считается достигнутым, когда новый разработчик может:

```bash
git clone <repository>
cd tender-parser
docker compose up
```

и после настройки переменных окружения получить работающий сервис без ручной установки большого количества зависимостей.
